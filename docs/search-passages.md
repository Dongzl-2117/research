# 搜索片段：实现、冻结验收与交接

搜索「Costco 商业模式」应展示解释会费、价差、采购和周转如何相互作用的原文。
本 PR 改善了候选覆盖、局部主体归属、排序、可见窗口和证据版本；冻结合成集的页面门槛已在本地达到。
**真实语义模型未验收，PR 保持草稿，不能把这些结果说成已经具备任意主题理解。**

## 实际链路

`/search` → `search_articles` → 查询解析 → 词法/向量/公司上下文候选 → 局部证据排序 → 文章卡片及原文窗口。
原实现已经给段落打分，并非文章命中后随便取摘录；问题是公司名、主题、标题上下文混分，
随后又强制让全词命中文章先排，主题词没出现的机制段会留在后面。旧版 88 字预览可能截掉机制，
两条摘录还共用第一条链接。

`/ask` 另有模型扩词、分批阅读与回答整合。普通搜索不调用聊天模型、不排导读任务。
问库沿用原有预算与排序；JSON chunk 查询共用局部打分，候选份量仍由其预算控制。

## 搜索分层

1. **解析实体与主题。** 公司从配置表按别名自动机识别，作者、显式范围、引号和排除词保持独立。
   向量查询使用去掉公司名的主题文字，不靠实体名称本身制造主题相似度。
2. **并列候选通道。** 保留全文索引各路与现有向量候选。搜索页另从公司提及表取有上限的文章上下文，
   不要求目标别名或题面词恰好被分词命中。该通道最多 120 篇、每篇 24 块、总计 2000 块，再补必要的相邻块；
   这不是穷尽召回，超长文后部或更早的文章仍可能漏掉。原文、OCR、当前译文均可进入。
3. **验证局部主体。** 在原文句子/必要分句内连结名字与陈述；本句显式主体优先于远处标题。
   章节、当前块已转谈外公司、或前块仍在谈外公司时，无显式目标名的句子不能从旧标题换回目标。
   中性章节间的明确代词可以继承相邻原文，显示必要上文，不要求两个 heading 文本相等。
   匿名材料不能仅因经营机制类似，就自动推断成目标公司。
4. **分别计算主题和弱先验。** BM25 只读合格局部原文，公司词和文章标题不替正文提供主题得分。
   词法与可用向量按现有 0.65/0.35 权重融合，另有小额公司语料先验：按独立原文的内容共现排列候选，
   单篇重复堆字不会重复计文档频率。它没有领域同义词表，也没有公司专属答案模板；**它不是语义相似度**。
   先验不增加主题覆盖率、不产生“语义相关”标签。仅凭先验入选时显示“同公司原文，主题待核对”。
   裸题面、明确否认的归属不算事实证据；“商业模式是……”也可能是真定义，保留为不确定候选，不能硬删。
5. **先排证据再聚合。** “含全部检索词”只作统计，不设优先档。每篇最多两个窗口，连续同主体论述可带必要邻块。
   分页前跨文折叠相同证据。指纹包含实际 before/中心/after，主体依赖标题或章节时也包含该依据；
   保留数字、标点和否定词，不用近似相似度把不同事实合并。不同来源的同一句若必要上文为 90% 和 95%，须都保留。
6. **原文展示与回链。** 局部窗口只截取连续原文，不改写、不拼造句子；保留完整块正文供引用核对。
   中心窗口最多约 500 字，上下文另有限额，每条摘录独立链接到原块、语言和锚点。
   整块向量不能转给裁切后另一句话；仅完整合格窗口可沿用块级语义分。没有局部重排模型时保守降级。

主体判定仍是局部规则：别名表未覆盖的公司、复杂转述/否定、远距离指代或同公司不同主题不能保证正确。
当前没有新增或默认启用语义重排服务。正确的下一层应在这些局部窗口上检验真实双语编码/重排器的主题相关性，
并与主体约束分别评估；不能让一项向量相似度同时充当公司归属和事实支持。

**通过这组门槛仍不能证明通用语义。** 额外反事实观察中，查询没有对应资料的“Costco 门店碳排放”仍列出会费、
采购等公司上下文；词法上偶合“门店”也不代表讨论了碳排放。
记录见 [counterfactual-6dd0319.json](../tools/retrieval_eval/acceptance/results/counterfactual-6dd0319.json)。
这说明弱先验只是提供相关公司候选；任意隐含主题、中文查询英文材料的真实理解仍需要模型验证。

## 正确性、回归和性能

- 旧译文 hash 过滤覆盖正文/标题/全文索引/整篇/邻上下文/三条向量候选；旧记录仍可阅读，不做正式库清理。
- 显式公司范围不丢失；冲突作者范围取空交集；原文/OCR/译文可共存，不因存在任意译文删除英文/OCR。
- 选择性吸收 #73 的模型、当前块及标题/章节/正文 hash 检查，向量请求前后复核，拒绝键本轮跳过。
  没有吸收其部署、身份或启动协议。#84 的翻译完整性改动已在 main，本 PR 额外处理旧译文作为检索证据的问题。
- 长文未读全时，即使没有章节标题也把覆盖不足传给各批模型和统计；不把未给出的原文当成不存在。
- 本地 585 条单元、集成和计分器边界测试通过，无跳过；ruff、pip check、diff 检查通过。
  旧测试中“无公司天气段排在部分命中后”的断言改为拒绝无主体段；计数文案断言同步更新，没有跳过测试。
- 合成回归覆盖局部主体转场、不同 heading 的指代、全词题面、英文连续解释、转载、不同数字上下文、
  以及整块语义分错误迁移到局部句。固定向量只验证契约，不代表真实模型效果。
- 原 1500 篇/10463 块基线通过，`baseline.json` 未改；问库平均准确率 84%，搜索前 20 篇准确率七题均 100%。
  这是旧基线的文章口径，不能冒充当前 DOM 片段指标。
- 自建主题集、冻结页面门槛和计分器边界已加入 CI 的检索步骤；页面/摘录修改也会触发该步骤。
  保持现有 draft 跳过条件，未启用、重试或绕过被拒工作流。

延迟必须区分环境和口径：冻结小集合逐题热路由 20 次记录 p50/p95；大合成基线是实际一次检索耗时。
