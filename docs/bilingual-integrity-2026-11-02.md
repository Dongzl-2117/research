## 历史资料：只读分类到独立验收

使用 `research-bilingual-qa --classify`：走只读连接，不跑迁移、不写表、不调模型，且不能和 `--llm` 混用。先点名或小范围检查，分类含 `recorded`、`lossless-display-only`、`unmapped-review`、`retranslation-review`，细节见 [译制文档](translate.md)。

1. 保留旧稿、原始与展示输入及已有对应证据；仅在私有环境核对，不发布真实原文或订阅地址。
2. 无损重建候选必须同时证明源/译身份、顺序、出现次数、独有措辞和资源均保留。段数相等、去重后相等、相似度高不能生成对应证据，也不能回填为已核验。
3. 没有足够证据的旧稿完整分开显示并保留警告。若只是格式变化且映射证据充分，可另提针对性重建补丁；不可凭本次代码升级批量改写。
4. 真实错译、缺译或被覆盖的金额，无法从现有材料无损恢复时，才列入重译候选。逐篇估算费用、另行获得授权、保留旧版本后再执行，并核对新旧事实和真实页面。
