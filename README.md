# 投资研究库

给 **investment.zldong.com** 用的私人研究库。仓库名仍然是 `research`。

这里保存几位作者的全文归档。首页按天推送，也可以按作者、按公司分模块查看，并做中文全文检索。它不是新闻流水线。

## 运行

```bash
cp .env.example .env
docker compose up -d --build
```

浏览器只通过本机 `http://127.0.0.1:8088` 访问。公网入口是 Cloudflare Tunnel 转到这个地址，不用登录就能看（应用自己也不提供登录）；问库要花模型的钱，按全站限次数，见 [docs/llm.md](docs/llm.md)「给 AI 的接口」。部署步骤见 [docs/deploy.md](docs/deploy.md)。合并进 main、CI 通过的改动由 Mac mini 上的定时任务自己上线，见同一页「更新」。

## 页面

- 按天：首页。只排 `timeline: true` 的来源（公众号、知识星球；飞书文库不进这一列）。文章按上海日历从新到旧，同一天里也是新的在前。翻页按整天翻，可以跳到某一天（`/?date=YYYY-MM-DD`）。点日期进入日汇总。卡片优先显示摘要；还没有摘要时用正文里的一句实质内容，不拿点赞、sn、时间戳当导读
- 按天的首页顶部有「最近观点」：按最近一条观点的时间排，不限持仓。收起时是一行公司名；展开后有导读的公司在下面显示库里已有的导读，没有导读就只留态度和近 30 天篇数，不把判断原文铺开。备份、定时任务、LLM 出了问题，或者定时导入的来源停更明显超过平时的间隔时，顶上提示一行；正常时什么都不显示
- 作者：每位作者的篇数、时间跨度、最近一篇、常深入谈的公司；作者页可以只在他的文章里检索
- 公司：列表按最近一条判断的日期排，每行是近一年的态度小图、看好 / 两面 / 看淡条数和最近一条判断，可按市场筛。页面上不标「持仓 / 观察」。有判断的公司页分三页：概览（每位作者现在怎么看：按月态度图加最近三条判断；下面是主要论点，一条一行，点开看理由、原话和出处）、判断（一条一行，按月分组，点开看理由、风险、推翻条件、要盯的指标和原句，可按作者、态度、论点筛）、文章（按月的深入 / 一带而过柱状图、「谁在谈」、按年份分组的文章，默认只看深入提及，每篇显示提及原句）。还没有判断的公司只有文章一页。论点要判断够数（至少 4 条）才有，只由 `research-theses` 写：打开公司页不补（网页不触发摘要、判断、论点这类花模型钱的任务），夜间补论点默认关（`THESES_ENABLED`）。见 [docs/llm.md](docs/llm.md)「观点时间线」
- 检索：输入关键词或直接问一句话。所有词都命中的文章排前面、按相关度排序，每篇给最相关的原文段落；其后是只命中一部分的。图片里的字（OCR）也能搜到。可按作者、公司、日期过滤，检索词是公司或作者名时直达。怎么找、准不准、库大了快不快见 [docs/retrieval.md](docs/retrieval.md)
- 问库：先在库里召回最相关的原文段落，马上列出来；模型在后台补同义说法、再检索一遍，只依据原文整合，先写判断、再写作者给出的机制，数字只作证据，每句带出处。资料多时分批读完再汇总。写完逐句核对出处，数字、引号、作者、日期对不上的列出来。每段原文可以标「不相关」，也可以补「漏了」的文章，这些标注用来回放评测
- 文章：标题、时间和正文。从问库、观点的出处点进来，直接滚到被引用的那几段并标出来。底部「同期别人怎么看」列出别的作者前后 30 天对同一家持仓公司的判断。作者改过或删过的稿，署名行标出来，点进去看各版改了什么。英文稿可站内译成中英对照（见 [docs/translate.md](docs/translate.md)）。图片从本机磁盘读，外链图片也下载到本地。Markdown / JSON 仍在 `/api/v1`
- 重复文章：认出来的同一篇，每组留下哪份、藏起哪几份、重合多少，认错了点一下拆开

给 AI 用的 JSON 接口、MCP 和 `/llms.txt`，以及默认 Grok、可切回的 DeepSeek，见 [docs/llm.md](docs/llm.md)。

## 来源

白名单在 `config/sources.yaml`。现在启用方伟公众号、方伟知识星球、乘风破浪、林文丰飞书、孤独进化体、Stratechery、雪球「黑黑无常」。林文丰公众号停用，不入库。黑黑无常只导入已经抓下来的原创帖和长文，进首页按天。

持仓和观察名单在 `config/portfolio.yaml`，按公司表里的中文名写。页面上不展示这份名单，JSON 里的 `portfolio` 字段仍读它。观点、论点和首页「最近观点」不按它过滤。

新文章靠 Mac mini 上的定时抓取进来：方伟公众号和方伟星球每天各抓两次，孤独进化体每天抓一次（`scripts/crawl-*.sh`，launchd 安装见 [docs/backup.md](docs/backup.md)）。乘风破浪、黑黑无常还没有定时抓取，要手动导入。AIHOT 已下线。

导入命令、幂等规则、改稿删稿怎么处理、去重、外链图片和计数报告见 [docs/ingest.md](docs/ingest.md)。方伟星球补真实钟点、林文丰目录树也在那里。公司提及的判定和歧义别名的规则见 [docs/mentions.md](docs/mentions.md)。备份、试恢复、夜间补齐、定时增量导入和出问题时的提示见 [docs/backup.md](docs/backup.md)。图片里的字见 [docs/ocr.md](docs/ocr.md)。

## 数据

Postgres 使用 zhparser 做中文全文检索。正文在库里，图片在 `data/images`。不要把 `.env`、归档压缩包或 `data/` 提交进仓库。

正文另外切成段落块存在 `article_chunks`，检索片段和问答引用落在块上；英文文章的中文译文也切块进检索。同一篇从两条路导入的，只留一个主版本。语义检索用 pgvector（数据库镜像已装），向量存在 `chunk_embeddings`，配了 `EMBEDDING_BASE_URL` 才启用，见 [docs/retrieval.md](docs/retrieval.md)「语义检索」。

## 开发

```bash
pip install --require-hashes -r requirements-dev.lock
pip install --no-deps -e .
ruff check .
pytest
```

依赖的版本和 hash 锁在 `requirements*.lock` 里，改依赖、升级依赖用 `scripts/lock.sh`，见 [docs/deploy.md](docs/deploy.md)。

集成测试需要带 zhparser 的 Postgres，并使用名为 `research_test` 的库。`docker compose up -d db` 之后创建这个库即可。CI 会自己构建数据库镜像并跑这些测试。改了检索相关的文件时（清单见 `.github/workflows/ci.yml` 里的 `retrieval`），再用 1500 篇的评测语料跑一遍检索评测，准确率、召回率比基线退步就失败；每周一和手动触发时这一步照跑。改了 Dockerfile、pyproject.toml 或锁文件时，另外构建应用和 OCR 镜像，认一张样图。

测试样本里不放真人的名字。从群聊、公众号留言区、星球评论截下来的样本，群友和评论者的昵称、群名、店名都换成虚构的（王小明、李四这类）；只有来源作者本人用真名，比如方伟，规则要靠它认出作者。

## 本机相关性标注

独立收集同一查询下两段原文的相关性偏好，提供可回放 JSONL、冻结分组和本机页面；不自动连接资料库或模型。[启动与接口说明](docs/relevance-annotations.md)。

算法参数的本机双方案对照、使用方式和生成费用边界见 [算法实验台](docs/algorithm-experiments.md)。保留独立本机入口，并提供默认关闭、需要可核验所有者认证的网站管理接入；可显式选择站内模型。默认不调用模型或改变搜索。
